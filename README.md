# Shipping Company Database

This project is a database design and implementation exercise for a shipping company. It includes an entity relationship model, a relational schema, sample data, and SQL queries that model the core operations of a shipping business.

## Project overview

The database is designed to support the management of:

- departments and department managers
- employees and their supervision hierarchy
- customers and their shipments
- shipment records and shipment locations
- dependents for employee records and benefits

## Main database concepts covered

- ER modeling
- relational schema mapping
- normalization and referential integrity
- SQL table creation
- sample data insertion
- query examples and verification

## Repository contents

- ER diagram
- logical schema design
- SQL script for table creation and data setup
- example queries for reporting and validation
- documentation describing requirements and design choices

## Example schema areas

- Department
- Employee
- Shipment
- Customer
- Dependent

## How to use

1. Open the SQL script in the repository.
2. Import or run it in a database environment such as Oracle, PostgreSQL, or another SQL-compatible system.
3. Execute sample queries to validate the design.
4. Extend the schema if needed for more advanced shipping operations.

## Typical use cases

- employee and department tracking
- shipment assignment and department ownership
- customer order and receiving information
- basic reporting and operational queries

## Notes

This project is designed as a learning and design exercise focused on database structure and SQL practice. It demonstrates how a real-world business process can be represented in a relational database.

## Goal

The main goal is to model a shipping company in a clean, understandable way while practicing database design concepts and SQL implementation.
